# UI assets

`world-map-noborders.svg` is the borderless world map published by
Scratchinghead on Wikimedia Commons under the CC0 1.0 public-domain
dedication. The installer deliberately uses the borderless edition so its
timezone picker does not assert or imply political boundaries.

Source: <https://commons.wikimedia.org/wiki/File:WorldMap-Blank-Noborders.svg>
